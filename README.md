# The Steps of Haneul (하늘의 걸음)

등록 및 조회 시스템

## 프로젝트 구조

```
├── index.html          # 메인 HTML 파일
├── css/
│   └── styles.css      # 스타일시트
├── js/
│   └── app.js          # JavaScript 애플리케이션 로직
├── assets/
│   └── back.jpg        # 배경 이미지
└── README.md           # 프로젝트 설명서
```

## 기능

- **팀원 등록**: 이름, 팀명, 사진을 등록
- **팀원 조회**: 등록된 팀원 정보 조회
- **이미지 저장**: 사원증을 이미지 파일로 저장

## 기술 스택

- HTML5
- CSS3 (반응형 디자인)
- JavaScript (ES6+ 모듈)
- Firebase Realtime Database
- Google Apps Script (이미지 업로드)

## 사용법

1. 웹 브라우저에서 `index.html` 파일을 열기
2. "등록" 또는 "조회" 버튼 클릭
3. 필요한 정보 입력 후 진행

## 브라우저 지원

- Chrome (권장)
- Firefox
- Safari
- Edge
